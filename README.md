# Ocean Basketball Center - Frontend Application

Website quản lý trung tâm bóng rổ Ocean Basketball được xây dựng bằng **Next.js 15 App Router**, **TypeScript** và **Tailwind CSS**.

## 🛠️ Công nghệ sử dụng
- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **State/Hooks**: React 19 Hooks

## 🚀 Hướng dẫn khởi chạy dự án

### 1. Cài đặt phụ thuộc
```bash
npm install
```

### 2. Cấu hình Biến Môi Trường (.env.local)
Tạo file `.env.local` tại thư mục gốc:
```env
NEXT_PUBLIC_API_URL=http://localhost:8080/api/v1
```

### 3. Chạy ở môi trường Development
```bash
npm run dev
```
Mở trình duyệt tại `http://localhost:3000`.
